Sistema Celulares Jireh

Plataforma integral de gestión analizada y diseñada por estudiantes del Instituto Continental para optimizar las operaciones técnicas y comerciales en Villa Perené.

🔗 Documentación y Alcance

🏪 El Negocio

Bajo la gerencia de Yuber Vicaña Mapele en Villa Perené, el establecimiento destaca por su especialización en reparación de hardware de celulares, microsoldadura de precisión y atención comercial.

💻 Stack Tecnológico

El desarrollo se plantea sobre un entorno virtual de Python utilizando el framework Flask y SQLAlchemy. La persistencia de datos se diseña en MySQL (modelado en MySQL Workbench).

🌐 Integración CI/CD

Para agilizar el desarrollo y mantener un código limpio, la propuesta integra un módulo automatizado mediante GitHub Actions. Esto permite la validación instantánea del código.
